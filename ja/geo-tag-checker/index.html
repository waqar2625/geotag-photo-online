What Is a Photo Geo Tag?

A geo tag (also written as geotag) is a set of GPS coordinates — latitude and longitude — stored inside a photo's EXIF metadata. When your phone or camera has location services enabled, it automatically writes these coordinates into every photo you take. The geo tag tells any photo app exactly where the picture was shot.

Geo tags are what make your photos appear on maps in Google Photos, Apple Photos, and Lightroom. They power the "Places" album, the location search, and the map view in every major photo platform.

When to Use a Geo Tag Checker

Before Sharing Photos Online

Photos taken with a smartphone contain your exact GPS coordinates. Before posting a photo taken at your home, workplace, or child's school, check whether it contains location data and strip it with our Remove EXIF Data tool if needed. Major platforms like Facebook and Twitter strip EXIF on upload, but many platforms — including forums, Craigslist, and personal websites — do not.

After Geotagging Photos

If you used our Geotag Photos tool (or any other geotagging software), use this checker to verify that the GPS coordinates were written correctly. The map view makes it easy to confirm the pin is in the right spot.

Debugging Photo Library Organization

When photos don't appear in the right location in Google Photos or Apple Photos, the issue is almost always missing or incorrect EXIF GPS data. Use this tool to check the raw coordinates and identify whether the problem is a missing geotag, an inaccurate GPS fix, or a photo format issue.

Forensic & Legal Verification

Journalists, investigators, and legal professionals use geo tag checkers to verify the claimed location of submitted photographs. While EXIF data can be modified, checking the embedded GPS coordinates is an important first step in photo authentication.

How the Geo Tag Checker Works

When you drop a photo onto the tool, JavaScript reads the file using the browser's File API without uploading anything. The exifr library parses the binary EXIF header and extracts the GPS-related tags: GPSLatitude, GPSLongitude, GPSAltitude, GPSLatitudeRef, GPSLongitudeRef, and GPSImgDirection.

If GPS data is found, the tool converts the DMS (degrees-minutes-seconds) values to decimal degrees and plots the location on an interactive map using Leaflet and OpenStreetMap tiles. The only network request is loading the map tiles — your photo data never leaves your device.

よくある質問

What does a geo tag checker do?

A geo tag checker reads the EXIF metadata stored inside a photo file and looks for GPS coordinate fields (GPSLatitude, GPSLongitude). If those fields exist, the tool displays the coordinates and shows the location on a map. If they don't exist, the tool tells you the photo has no location data.

Why would I need to check a photo's geotag?

Common reasons include: verifying that a geotagging tool wrote the correct coordinates, checking whether a photo contains your home location before sharing it online, confirming GPS data exists before uploading to a platform that requires it, and debugging issues with photo library organization (e.g., 'why isn't this photo showing up on the map in Google Photos?').

What image formats are supported?

The tool supports JPEG/JPG, PNG, TIFF, WebP, and HEIF/HEIC images. JPEG is the most common format with EXIF GPS data, but modern phones (especially iPhones) may store photos in HEIC format with the same metadata.

My photo has GPS data but the location seems wrong. Why?

GPS accuracy in photos depends on the device's GPS signal at the time of capture. Indoor photos, photos taken in urban canyons (between tall buildings), or photos taken while the GPS was still acquiring a fix can have inaccurate coordinates. If you need to correct the location, use our Geotag Photos tool to overwrite it with the correct coordinates.

Does this tool show other EXIF data besides GPS?

The Geo Tag Checker focuses specifically on location data — coordinates, altitude, and direction (if available). For a complete view of all EXIF metadata including camera model, date/time, exposure settings, and more, use our EXIF Viewer tool.

How do I remove GPS data from a photo for privacy?

Use our Remove EXIF Data tool. It strips all metadata — including GPS coordinates, camera information, and timestamps — from your photos. This is recommended before sharing photos on social media or sending them to people you don't want to know the photo's location.

Can I check GPS data on iPhone HEIC photos?

Yes. The tool supports HEIC/HEIF format used by iPhones. Upload the .heic file directly — no conversion needed. If the iPhone had location services enabled when the photo was taken, you'll see the GPS coordinates.

Is my photo uploaded to a server when I use this tool?

No. The file is read and analyzed entirely in your browser using the exifr JavaScript library. No data is transmitted over the network. You can verify this by opening your browser's network inspector — you'll see zero requests when you drop a photo.
